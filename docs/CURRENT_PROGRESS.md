# QB-WebUI 开发计划

## 当前进度 (2026-03-18)

### ✅ 已完成的功能

1. **登录页面**
   - 简化的登录表单（仅用户名和密码）
   - 默认连接到 localhost:8088
   - 登录成功后跳转到主界面
   - Cookie (SID) 自动保存到 localStorage

2. **路由和认证**
   - Vue Router 配置
   - 导航守卫检查认证状态
   - 403 错误处理和自动跳转到登录页
   - 修复了登录页面的重定向循环问题

3. **API 代理配置**
   - Vite 代理配置：所有 `/api/*` 请求转发到 `localhost:8088`
   - API 客户端强制使用代理模式

4. **主界面布局**
   - 侧边栏菜单（任务列表、分类、标签、设置）
   - 顶部导航栏（添加任务、登出按钮）
   - 条件渲染：登录页面不显示主布局

5. **Dashboard 仪表盘**
   - 实时统计卡片（总任务、下载中、上传中、已完成、暂停、错误）
   - 速度监控（下载/上传速度、总量）
   - 任务列表（表格显示、搜索、筛选、分页）
   - 任务操作（暂停、恢复、删除）
   - 主数据同步（自动刷新机制）

6. **设置页面**
   - 显示和修改 qBittorrent 设置
   - 连接配置测试功能

7. **UI 优化**
   - CSS 变量系统（字体大小、颜色、间距）
   - 字体大小调整（text-xs: 12px, text-sm: 14px, text-base: 15px）
   - 任务列表列宽优化（速度列 140px，防止文本换行）
   - 侧边栏和任务区域间距调整

## 注意事项

1. 所有 `/api/v2` 接口访问都需要通过代理中转到本机的 8088 端口
2. 登录页面不需要输入后台地址和端口，默认使用 localhost:8088
3. Cookie (SID) 会自动保存到 localStorage，登录状态会持久化
4. 403 错误会自动跳转到登录页面
