# UI 重设计文档

## 1. 概述
本设计文档针对 Day 5 开发任务 "UI 重设计"，重点是优化浅色模式下的布局、间距和视觉层次。

## 2. 目标
- 优化页面布局和组件间距
- 改善视觉层次结构
- 使用蓝色主色调 (#409EFF)
- 提升整体用户体验

## 3. 详细设计

### 3.1 架构与组件
- **组件**: `src/views/Settings.vue`, `src/views/Dashboard.vue`, `src/App.vue`
- **样式**: 新增 `src/styles/variables.css` 定义 CSS 变量
- **全局样式**: 更新 `src/main.js` 引入样式文件

### 3.2 UI/UX 设计
1. **配色方案**:
   - 主色: #409EFF (蓝色)
   - 背景色: #F5F7FA (浅灰色)
   - 文字颜色: #303133 (深灰色)
   - 辅助文字: #909399 (浅灰色)

2. **布局优化**:
   - 页面内边距: 20px
   - 卡片内边距: 24px
   - 元素间距: 16px
   - 网格系统: 12列，响应式断点

3. **视觉层次**:
   - 主标题: 20px bold
   - 副标题: 16px bold
   - 小标题: 14px bold
   - 正文: 14px normal
   - 辅助文字: 12px

4. **组件样式**:
   - 卡片: 增加阴影、圆角 (8px)
   - 按钮: 统一尺寸、颜色、悬停效果
   - 表格: 优化行高、间距、状态标签

### 3.3 数据流
1. 用户访问页面 -> 加载全局样式
2. 组件渲染 -> 应用 CSS 变量
3. 用户交互 -> 触发悬停效果

### 3.4 错误处理
- 样式加载失败 -> 使用默认样式
- CSS 变量不支持 -> 降级处理

### 3.5 测试策略
- **手动测试**: 检查各页面布局、间距、视觉层次
- **浏览器兼容性**: 测试主流浏览器 (Chrome, Firefox, Safari)

## 4. 代码变更要点
- 新增 `src/styles/variables.css` 文件
- 更新 `src/main.js` 引入样式文件
- 修改 `src/views/Settings.vue` 样式部分
- 修改 `src/views/Dashboard.vue` 样式部分
- 修改 `src/App.vue` 样式部分
