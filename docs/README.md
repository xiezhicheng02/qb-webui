# QB-WebUI 文档目录

这个目录包含了项目的文档文件，用于记录项目信息、开发计划和技术细节。

## 文档列表

### 开发计划
- **[DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)** - 30天详细开发计划表
  - 每天1小时的开发任务安排
  - 四个阶段：基础框架、核心功能、设置优化、测试发布
  - 详细的完成状态跟踪

### 技术文档
- **[TECHNICAL_DOCUMENTATION.md](TECHNICAL_DOCUMENTATION.md)** - 完整技术文档
  - 项目架构设计
  - 技术栈选择
  - 核心对象设计（Torrent, Settings, TransferInfo）
  - 组件设计
  - 状态管理方案
  - API 接口设计
  - 使用文档和开发指南

### 项目状态
- **[PROJECT_STATUS.md](PROJECT_STATUS.md)** - 当前项目状态
  - 最后更新时间
  - 项目基本信息
  - 当前开发进度（已完成/待完成）
  - 已创建文件列表
  - 下次继续开发指引

### Claude 上下文
- **[CLAUDE.md](CLAUDE.md)** - Claude Code 上下文文件
  - 项目概述
  - 技术栈
  - 项目结构
  - 当前进度
  - 开发命令

### 对话记录
- **[对话记录.txt](对话记录.txt)** - 完整对话历史
  - 所有对话内容记录
  - 项目创建过程
  - 功能实现记录

## 使用说明

1. **查看开发计划**: 打开 `DEVELOPMENT_PLAN.md` 了解30天开发安排
2. **了解技术细节**: 打开 `TECHNICAL_DOCUMENTATION.md` 查看架构设计
3. **跟踪进度**: 打开 `PROJECT_STATUS.md` 查看当前状态
4. **继续对话**: 查看 `对话记录.txt` 了解历史对话

## 文件组织原则

- **直接开发相关**: 源代码、配置文件、依赖文件
- **文档相关**: 计划、技术文档、状态记录、对话历史

这样可以保持项目根目录整洁，同时方便查找相关文档。
