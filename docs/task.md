## 全局要求
1. 项目的各种功能实现需要的API请参考WebUI API (qBittorrent 5.0) - Clean.md 这个文件
2. 整个项目尽量使用element-ui的组件来完成， 不要使用其他组件库
2. 整个项目尽量使用Tailwind CSS开设置样式
3. 设计UI和交互需要符合美观，好用的原则， 不要使用复杂的布局和交互， 保持简单和直观
4. 颜色使用要协调，要与全局保持一致



## 需求1
1. 左侧目录区， 其中分类模块， 使用el-button来展示分类， 选中的分类需要显示深色背景色， 未选中的显示浅色背景色
2. 分类要支持管理功能， 可以新增，修改，删除分类，


## 需求2
1.左侧区域，标签模块， 使用el-tag来展示标签， 选中的标签需要显示深色背景色， 未选中的显示浅色背景色
2. 标签要支持管理功能， 可以新增，修改，删除标签，

## 需求3
1. 右侧区域，任务详情， 使用el-drawer组件来展示任务详情， 抽屉组件的宽度为50%
2. 抽屉组件的标题为任务详情
3. 抽屉组件包含四个tab， 其中tab1为任务详情， tab2为文件目录，显示文件大小和下载进度， tab3为peers列表，并实时更新， tab4为tracker列表信息
4. 需要你参考WebUI API (qBittorrent 5.0) - Clean.md这个文档来实现相关的功能


## 需求4：
任务卡片中， 把设置上传下载限速功能， 设置优先级功能， 删除功能都集成到右键菜单中， 右侧就不要有相关的按钮了


## 需求5：
顶部的上传速度，下载速度，上传量等信息， 实时更新， 采用的是el-statistic 组件, 导致文件单调， 间隔不合理， 大小不合适， 请优化下它， 可以采用不同的颜色来显示信息， 调整间隔， 

## 需求6：
1.顶部右侧的添加任务按钮， 点击之后的弹窗太丑了， 弹窗中有两个tab， 请使用el-tabs组件来替换, 第二个tab的名称改成“种子文件”， 种子文件tab中需要支持上传种子文件的功能， 请使用el-upload组件来实现。 
2. 弹窗中还需要用户必须设置分类， 如果没有用户想要的分类， 还需要支持用户新增分类功能， 请设计好分类的展示，新增的交互和UI, 要美观 
3. 弹窗中需要用户可以设置标签， 如果没有用户想要的标签， 还需要支持用户新增标签功能， 请设计好标签的展示，新增的交互和UI, 要美观 
4. 还需要支持用户设置下载内容的保存路径， 用户可以不设置，那就使用默认全局的保存路径
5. 添加任务之后， 任务信息需要实时更新到任务列表中
